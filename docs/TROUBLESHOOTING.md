# Troubleshooting

## Start with `go2apk doctor`

```bash
$ go2apk doctor
found:  go (/usr/local/go/bin/go)
found:  java (/usr/bin/java)
missing: adb
found:  Android SDK (/home/you/Android/Sdk)
found:  sdkmanager
missing: platform android-36 (installed: android-35)
found:  build-tools 36.0.0
warning: ndk 27.2.12479018 not installed, falling back to 26.0.0 (installed: 27.2.12479018, 26.0.0)
```

`doctor` reports what is present and what is missing, rather than checking that
a few tools exist and declaring success. It compares the SDK platform,
build-tools and NDK revisions against the ones in `go2apk.yaml`, and tells you
what *is* installed when yours is not among them — which is the difference
between "something is wrong" and "here is the one thing to change".

`adb` is reported as missing in the example above and that is fine: it is only
needed to install a build onto a device, not to build one.

A `warning` line means the build will still work, but not with the version you
configured. Fix it by installing the configured revision or by changing
`go2apk.yaml` to match what you have — and then regenerate the workflows, since
they pin the same versions:

```bash
go2apk workflow init
```

## The Android SDK is not installed

`go2apk sdk install` writes the installer scripts for the versions in
`go2apk.yaml`; it does not download anything itself. Run whichever script
matches your shell:

```bash
scripts/install-sdk.sh      # Linux, macOS
scripts/install-sdk.ps1     # PowerShell
```

They use Google's official command-line tools. To install elsewhere, set
`ANDROID_HOME` (or `ANDROID_SDK_ROOT`) and run the script — it honours both.

## `check` fails on my generated files

```
./events_gen.go:16: cannot use func(checked bool) {} as func() value
```

This means a generated file left over from an earlier run no longer matches your
code. Go2APK deletes its own generated Go before parsing, so if you still see
this, the file is not carrying its `// Code generated by go2apk. DO NOT EDIT.`
marker — it was committed, renamed, or edited. Delete it and run `go2apk check`
again. See [Generated files](GENERATED_FILES.md).

## A widget's handler is never called

Handlers are dispatched **by name** over JNI, so a widget needs an ID. A widget
with a handler and no ID is given a generated one, and the generated Java calls
`NativeBridge.sendEvent("<id>_onclick")`.

The other cause is a handler with the wrong shape. `ui.Switch` and
`ui.TextField` pass a value to their handler:

```go
ui.Switch{ID: "notify", OnChanged: func(checked bool) { ... }}   // func(bool)
ui.TextField{ID: "search", OnChanged: func(text string) { ... }} // func(string)
```

If the handler takes no arguments, the generated Go will not compile, because
there is no way for the value to reach it. See
[Building a UI](UI.md#widget-ids-and-events).

## `go2apk: unknown flag`

```
$ go2apk build --obfuscat
go2apk: unknown flag "--obfuscat"
```

Flags are validated. Compare with the [command list](CLI.md) — this one is
`--obfuscate`.

## `unknown key` in `go2apk.yaml`

```
go2apk.yaml:14: unknown key "obfuscat"
```

Configuration is validated strictly, including unknown keys, so a typo is
reported with its line instead of being ignored. The full key list is in
[Configuration](CONFIG.md).

## Gradle cannot be found

Go2APK uses the Gradle wrapper when the project has one, and otherwise
provisions a Gradle distribution itself. To use your own Gradle, point
`GO2APK_GRADLE` at its binary. If you pin the downloaded distribution, set
`GO2APK_GRADLE_SHA256` as well.

## The release APK installs but cannot be published

It was signed with the debug key because no keystore is configured.
`go2apk release` prints a warning to stderr when this happens. See
[Release signing](CONFIG.md#release-signing).

## Nothing renders where I expected it

Two layout rules account for most surprises:

- A `Button` inside a `Column` with no explicit width collapses, because a
  `Column` stretches its children horizontally and an unset width reads as zero.
- In a `Row`, give a child a `Weight` rather than a width; a `Row` stretches a
  zero-width child by weight.

`go2apk check` reports the first case, and `go2apk preview` renders an HTML
approximation of the result. See [Building a UI](UI.md#layout-warnings).
